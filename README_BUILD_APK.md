# UDC SMS Assistant - Android OTP Forwarder
========================================================================
সহজে APK তৈরি করার বাংলা নির্দেশিকা (২টি সহজ উপায়)
========================================================================

উপায় ১: GitHub Actions দিয়ে ফ্রিতে ২ মিনিটে APK বিল্ড (সবচেয়ে সহজ)
------------------------------------------------------------------------
১. GitHub.com এ গিয়ে একটি নতুন রিপোজিটরি তৈরি করুন (Private বা Public)।
২. এই জিপের ভেতরের সব ফাইল সেখানে আপলোড করুন বা পুশ করুন।
৩. GitHub পেজের ওপরে থাকা "Actions" ট্যাবে যান।
৪. "Build Android APK" ➔ "Run workflow" বাটনে ক্লিক করুন।
৫. ২ মিনিটের মধ্যে রান শেষ হবে এবং নিচে "udc-sms-assistant-debug" নামে
   রেডি ইনস্টলযোগ্য APK ডাউনলোড করার লিঙ্ক পেয়ে যাবেন!

------------------------------------------------------------------------
উপায় ২: Android Studio দিয়ে কম্পিউটার থেকে APK বিল্ড
------------------------------------------------------------------------
১. এই জিপ ফাইলটি আপনার কম্পিউটারে আনজিপ করুন।
২. Android Studio ওপেন করে "Open" দিয়ে এই ফোল্ডারটি সিলেক্ট করুন।
৩. উপরে মেনু বার থেকে ক্লিক করুন:
   Build ➔ Build Bundle(s) / APK(s) ➔ Build APK(s)
৪. ১ মিনিটের মধ্যে নিচে ডানপাশে "locate" অপশন আসবে, সেখানে ক্লিক করলে
   ফোনে নেওয়ার জন্য রেডি "app-debug.apk" ফাইলটি পেয়ে যাবেন।
